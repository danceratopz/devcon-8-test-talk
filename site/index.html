07 // reorging away startup

Can it really be that easy?

The hard part: generating and rewriting the checklists.

generating // two sweeps

Sweep 1: collect every test's accounts.

One genesis for all: its state root and hash.

Sweep 2: generate each test's blocks on that genesis hash.

Chicken and egg: the genesis needs the tests, the tests need the genesis.

rewriting // the radio presets

pre-state

tx → post-state

test A

P1: 87.4

2 mangoes in the glove box, AC on max

handbrake turn → the Lambo spins out

test B

P1: 102.5

2 mangoes in the glove box, wipers on

reverse → the Lambo rolls back

Both want preset 1: one button can't hold two stations.

The fix: every checklist gets its own preset button.

Then one car runs every checklist. Easy, once they're generated and rewritten.
